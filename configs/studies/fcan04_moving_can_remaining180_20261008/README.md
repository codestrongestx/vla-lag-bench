# Moving can (ribbed): remaining 180

The 180 episodes of the ribbed 200-episode bank not in the random-20 pilot
(`../fcan04_moving_can_pilot20_20261008`), in ascending bank episode order with
local state indices 0–179. Each keeps its bank box placement, start phase and
direction; box placements repeat across states, as in the bank.
`selection.json` maps local episode IDs to bank episode IDs for both subsets,
which together cover bank episodes 0–199 exactly once. Generated by
`configs/experiments/dynamicvla/fcan04_moving_can_20261006/split.py`.

Protocol, speed grid (the LIBERO grid, 0.001–0.2 m/s, nine speeds), latencies
and modes match the pilot: 63 cells × 180 = 11,340 episodes. Combine with the
pilot by adding success counts per cell and dividing by 200.
